# Home Assistant integration 0.5.2

Integration-only maintenance release for existing Livolo installations. Keep the
existing integration entry and update through HACS/Marketplace, then restart HA.
The manual ZIP contains the same assembled integration and bundled client.

- Normal Configure menu offers Pair new device, refresh, forget, read-only firmware preflight and Settings.
- Manual registration, detection and pairing are grouped under Development, disabled by default per hub. Disabling it guards open manual flows without replaying commands.
- Native HA device deletion forgets only the selected peer and verifies removal before deleting its HA record; failures preserve the record.

The bundled client implementation is unchanged from 0.5.1. This release contains
no app, daemon or radio firmware payloads. Keep app 0.5.1, daemon 0.14.1 and radio
firmware 0.13. The 0.6.0 candidate and all-board firmware qualification remain
separate; this is not a complete project release.

Validation: 266 isolated tests against HA 2026.10.4 and the 0.5.1 maintenance
source, including native removal and asynchronous Development guards. Public
installer and live HA upgrade evidence is recorded separately after publication.
No new physical pairing, control or firmware qualification is claimed.

For rollback, restore the previous integration files and restart HA. Retain the
current daemon database and HA configuration; never restore historical forgotten
peers merely to roll back integration code.
