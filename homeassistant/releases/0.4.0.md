Livolo EC for Home Assistant **0.4.0** adds optional Web access, persistent
local firmware catalogs and native firmware transfer progress. The daemon
compatibility version remains **0.13**, native API revision 1 and UART protocol 3.

### Install and update

Use the [HACS/Marketplace integration channel](https://github.com/psires/ha-livolo-ec)
and [HA app repository](https://github.com/psires/livolo_ec). These are separate
software updates. Preserve the existing integration entry, configuration and
registry; restart HA after updating integration files. Software updates do not
flash a radio. The public firmware catalog remains empty.

The manual `livolo-ec-ha-0.4.0.zip` extracts into the HA configuration directory.
The integration channel's `livolo_ec.zip` instead has component files at its root
and is intended for HACS/Marketplace.

### Firmware maintenance

- `web_enabled` defaults to true. When disabled, the native authenticated API and
  firmware worker remain available to HA; the app's Open Web UI link is unavailable.
- `firmware_catalog` defaults to `bundled`. The `local` choice uses `/data/firmware`,
  preserving trusted administrator-provisioned artifacts across app updates.
- Missing or invalid local catalogs block firmware updates with an explanation;
  normal switch control remains available. There is no fallback to another catalog.
- Catalog changes refresh availability without a radio reconnect. Preflight and
  installation admission reject stale or invalid artifacts.
- HA uses its standard update action through the native API. Measured transfer
  progress is distinct from verified completion; durable job identity survives
  reconnects without replaying installation requests.

Exact-board compatibility, helper availability and hardware qualification still
apply. Emergency CLI maintenance is documented in
[FIRMWARE_FLASHING.md](https://github.com/psires/livolo_ec/blob/ha-0.4.0/docs/FIRMWARE_FLASHING.md).
Project-owned code remains BSD-2-Clause; external firmware and flashing dependencies
retain their own licences. Prior published releases are unchanged.
