Native Home Assistant integration baseline, published from commit
`fde0b494fed3b925e97c482524b874c1d98cd93b`.

### Included

- Native local-push switch entities through the authenticated Livolo daemon API,
  without requiring MQTT.
- Connection setup, credential repair, device registration and targeted pairing.
- A self-contained integration ZIP with its Python client and BSD-2-Clause licence.
- Companion HA app source build context for aarch64.

### Installation

Download `livolo-ec-ha-0.1.1.zip`, verify it using `SHA256SUMS`, and extract its
`custom_components/livolo_ec` directory into your Home Assistant configuration
directory. Restart Home Assistant and add the Livolo EC integration. Configure
the address and token of your running Livolo daemon.

The integration alone does not run the daemon or access the radio. The companion
app source archive is a local app build context, not a prebuilt container or a
Supervisor repository. See the [installation instructions at this tag](https://github.com/psires/livolo_ec/blob/ha-0.1.1/homeassistant/README.md).
This is a manual-install ZIP, not a configured HACS/Marketplace release.

### Versions and limits

The integration is **0.1.1**; its historical companion app and Python client are
**0.1.0**; daemon and radio firmware are **0.12**. Those independent version
numbers are preserved. Validation targets HA Core **2026.10.4**.

This baseline predates the standard HA firmware update entity and experimental
switch-profile detection; use HA 0.2.0 for those features. No radio firmware
binaries, signing keys or prebuilt Docker images are attached. Hardware support
and operating limits remain board-specific. Project-owned code is BSD-2-Clause;
dependencies retain their own licences.

The baseline has 28 passing HA/client/packaging tests. `release.json` records the
exact source commit and component versions; `SHA256SUMS` covers every supplied
asset except the checksum file itself. GitHub's generated source archives contain
the full historical monorepo; use the integration ZIP for manual HA installation.
